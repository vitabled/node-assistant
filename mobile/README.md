# NA Mobile (Android, Material 3)

Приложение для Android на Capacitor 7: через него можно полностью управлять Node Assistant с телефона.

## Как устроено

- **Стартовый экран** (`www/`, M3: top app bar, список серверов, FAB, диалог, switch, snackbar, тёмная/светлая тема).
  Здесь сохраняются адреса NA-серверов: на устройстве хранятся только URL и имя, токенов нет. Перед сохранением
  адрес проверяется ответом `/api/health`. Есть режим «сразу открывать последний сервер».
- **Управление.** После выбора сервера WebView открывает origin NA, и дальше работает его веб-интерфейс
  (M3-навигация `M3Nav`, все разделы, WebSocket-логи деплоя). Поэтому приложение покрывает ровно то, что умеет веб:
  отдельный клиент для 400+ ручек не нужен, и после обновления NA обновлять приложение не надо.
- **Сессия.** Вход и сессия NA хранятся в WebView на origin сервера. «Назад» на Android сначала идёт по истории
  WebView и возвращает к списку серверов, только потом закрывает приложение.
- **Разрешения.** `allowNavigation: ["*"]` и `cleartext` нужны, чтобы работали адреса по IP и `http://`.

## Команды

```bash
npm install
npm test                 # node --test: нормализация адресов, список серверов, автооткрытие
npm run apk              # cap sync + gradlew assembleDebug (нужен ANDROID_HOME, JDK 21)
# APK: android/app/build/outputs/apk/debug/app-debug.apk
```

Релизная сборка: `cd android && ./gradlew assembleRelease`. Берёт подпись из `~/.na-mobile/signing.properties`
(`storeFile`, `storePassFile` — файл с паролем, `keyAlias`). Если файла нет, собирается неподписанный APK.
Keystore в репозиторий не кладётся. Обновления нужно подписывать тем же ключом.
