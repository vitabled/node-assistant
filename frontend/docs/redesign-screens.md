# Redesign screen review — S1–S4 (remnawave)

Чек-лист дизайн-ревью после структурного редизайна (S1–S3) и полировки
поведения (S4). Это **не** гайд по цвету/палитре — про иерархию, разметку,
модалки, пустые состояния, анимации и отзывчивость. Скин `remnawave` — фон.

## Как снимать скрины

Репозиторий содержит два harness'а **без бэкенда** (сидят устройство-аккаунт в
`localStorage`, стабят **все `/api/**`** бенигн-JSON'ом из `apiStub()`, поэтому
экраны рендерятся без живого бэкенда). Требуется `chromium`:

```
cd frontend
npx playwright install chromium
npx vite --host            # в одном терминале (dev-сервер)
```

**Целевой скин редизайна — `remnawave`** (× light/dark, 1440/390):

```
node tests/e2e/redesign-shots.mjs http://localhost:5173 tests/e2e/shots/redesign
```

Снимает пустые состояния S4: Dashboard (Server uptime), DeployDashboard,
F2bList, UsersStats — desktop 1440 + mobile 390, тёмная/светлая.

**Общая матрица скинов** (`apple`/`console`, ключевые экраны) — прежний harness:

```
node tests/e2e/theme-shots.mjs http://localhost:5173 tests/e2e/shots
```

Таргетные размеры задаются в сценарии (`DESKTOP`/`MOBILE`).

| Формат | Viewport |
|---|---|
| Desktop | 1440 × 1400 (`redesign-shots`; в `theme-shots` базово 1280 — поправить `DESKTOP`) |
| Mobile | 390 × 844 (уже так в обоих) |

## Чек-лист по экранам

### 1. Dashboard (Xray uptime / Server uptime)

**Server uptime** — ключевой после S2/S4.

- [ ] Верхние Stat-карточки (Всего / Онлайн / Офлайн / Аптайм) — 2 колонки на
      мобиле, 4 на десктопе; при загрузке — skeleton (`.ni-skeleton`), не «—».
- [ ] Таблица серверов: страна+флаг (`FlagChip`), имя/IP, статус-дот
      (online/slow≥800мс/offline), аптайм 30д, спарклайн нагрузки, действия справа.
- [ ] **Пустое состояние** (нет серверов): иконка + заголовок «Нет отслеживаемых
      серверов» + подсказка + кнопка «Добавить сервер» (открывает модалку).
- [ ] Анимация появления: карточки/таблица fade+slide-up (Stagger), гейтится
      `prefers-reduced-motion` (в ОС `reduce` — мгновенно, без сдвига).
- [ ] Xray uptime: grouped-навигация по подпискам/странам, health-banner с rail,
      скрытые ноды в «Не отслеживаются».
- [ ] Mobile 390: таблица скроллится горизонтально, шапка липкая (`Table`),
      заголовочные кнопки не обрезаются.

### 2. DeployDashboard

- [ ] Toolbar (S2): поиск по IP/имени/домену + фильтр статуса (Seg) +
      primary «Новая нода» — на мобиле переносится (flex-wrap).
- [ ] Сетка карточек `ni-deploy-grid`; карточки fade+slide-up (Stagger).
- [ ] **Пустое состояние** (нет джоб): иконка Rocket + «Нет задач деплоя» +
      подсказка + кнопка «Добавить сервер».
- [ ] **Пустой поиск**: EmptyState «Ничего не найдено» + кнопка «Сбросить фильтры»
      (очищает query + statusFilter).
- [ ] Карточка в работе: тонкий прогресс-бар с pulse (`.ni-progress-pulse`),
      шаг «[N/M] …»; не дёргает всю сетку при стриме соседней карточки.
- [ ] Модалка нового деплоя: no `initial` → тянет дефолты из настроек.
- [ ] Mobile: карточки в одну колонку, кнопки ≥44px.

### 3. DeployCard expanded

- [ ] Заголовок: StatusIcon + домен + `ip:newSshPort`; rail слева по статусу
      (cyan=в работе, teal=успех, red=ошибка, серый=ожидание).
- [ ] Прогресс-бар с pulse при `running`; при успехе — зелёный 100%.
- [ ] SUCCESS: блоки Безопасность / Трафик / SSL (CertBlock) — до первого
      SSH-ответа показывается компактный skeleton (`ServerDataSkeleton`), а не
      стопка пустых секций.
- [ ] Управление компонентами (ManageBlock): переустановить/удалить с двухшаговым
      подтверждением; операции в `OpStreamModal` (второй `useTaskStream`).
- [ ] **Модалки S3**: «Сменить домен» (ReplaceDomainModal) и «Образ remnanode» —
      через общий `FormDialog` (blur-overlay, slide-up на мобиле, 150–200ms).
- [ ] Сворачивание успешной карточки (ChevronUp) → компактный `CollapsedCard`.

### 4. DeployForm

- [ ] Одностраничная панель с секциями: Сервер/SSH, Нода, Домен/SSL, Remnawave,
      Опции; collapsible-секции, упавшая валидация авто-раскрывает нужную секцию.
- [ ] Sticky summary-сайдбар справа (данные + CTA «Развернуть») на десктопе;
      на мобиле summary сворачивается/уезжает вниз.
- [ ] Примитивы S1: `Field`/`InputShell`/`Select` (custom dropdown)/`Toggle`
      вместо нативных `<input>`/`<select>`; min-target 44px.
- [ ] Mode-tabs Remnanode/HAProxy; gated-поля (CF-token только при cloudflare).

### 5. F2bList

- [ ] Заголовок + счётчик адресов (soft-badge, плюрализация).
- [ ] Кнопки всегда видимы (Сохранить/Собрать/Загрузить/Импорт/Экспорт).
- [ ] **Пустое состояние** (нет адресов): compact EmptyState «Список пуст» +
      подсказка + кнопка «Импорт»; textarea остаётся редактором.
- [ ] Поиск по строкам с предпросмотром совпадений; «Ничего не найдено» в превью.
- [ ] Импорт TXT/CSV/JSON с дедупом и пометкой подозрительных строк; экспорт Blob.

### 6. UsersStats

- [ ] 6 виджетов в grid 1/2 колонки (wide-виджет `w:2` растягивается `1/-1`).
- [ ] Сегменты-фильтры (Все/Нагрузка/Пользователи/Ноды) + «Редактировать»
      (move/resize/удалить виджет) + «Серверы» (скрытие).
- [ ] **Пустое состояние**: compact EmptyState «Данных пока нет» + подсказка
      (кнопки «Обновить» нет — виджеты тянутся только при смене периода/инстанса).
- [ ] Загрузка виджета — skeleton вместо текста «Загрузка…».
- [ ] «Все серверы скрыты» — отдельное состояние, не путать с «Данных нет».
- [ ] Mobile: сетка в 1 колонку, чарты (inline SVG) не вылезают за карточку.

### 7. Settings

- [ ] Вкладки (Theme/ApiTokens/и т.д.) — underline-табы `Tabs`, активная
      подсвечивается.
- [ ] Тема: Стиль (Apple/Консоль/Neon) + режим (Системная/Светлая/Тёмная) +
      акцент + плотность; применение императивно, зеркалится на бэкенд.
- [ ] Формы на примитивах S1 (Field/Select/Toggle), не нативные контролы.
- [ ] Mobile: длинные вкладки не обрезаются, таргеты ≥44px.

## Глобальные проверки (все экраны)

- [ ] Иерархия: заголовок > подзаголовок > контент; `--t-hi/mid/low/faint` по
      назначению; активное действие — accent, деструктивное — err.
- [ ] Контраст ≥ WCAG AA (есть `theme/contrast.test.ts`).
- [ ] Модалки: Esc + клик по оверлею закрывают, фокус замыкается, возвращается
      на прежний элемент.
- [ ] Анимации: 150/200ms, `useMotionEnabled()` (toggle `ni_motion` + OS
      `prefers-reduced-motion`); в `reduce` всё мгновенно.
- [ ] Пустые состояния — единый `EmptyState` (иконка/заголовок/подсказка/действие),
      без «серого текста в рамке».
- [ ] Mobile 390: ни один таргет не <44px, нет горизонтального скролла контента
      (кроме осознанных таблиц).

## Известные незакрытые темы (не в S4)

- 3 предсуществующих падающих теста не трогаем (App tab persistence /
  AuthScreen / PanelManageModal) — фикс вне этой волны.
- Скриншоты S4 (пустые состояния) уже сняты `redesign-shots.mjs` в
  `tests/e2e/shots/redesign/`; полный визуальный прогон с **данными** (не
  пустыми экранами) требует живого бэкенда или более богатого `apiStub`.
